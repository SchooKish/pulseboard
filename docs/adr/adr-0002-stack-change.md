# ADR-0002: Stack change

## Context

После первого поста мне были заданы вопросы насчёт выбранного мной стека.
Плюс были даны рекомендации.

## Options

* Ничего не менять
* Оставить в качестве бэкэнда Nest, а на фронте использовать связку tRPC + vite
* Остановиться на Nuxt - делать Fullstack приложение

## Decision

Решил остановиться на Nuxt Fullstack app. 
На данный момент приложение не подразумевает большого количества серверной бизнес-логики или кучи микросервисов.

## Consequences 

Вследствие этого решения мы получаем некоторые упрощения:
* Один репозиторий / не надо делать монорепозиторий
* Единый источник правды для типов
* Просто меньше кода

Nest требует от разработчика писать в определённой архитектуре, 
у Nuxt же такого нет → мне нужно разобраться в архитектуре бэкэнда,
какие есть подходы для его организации в приложениях такого масштаба
