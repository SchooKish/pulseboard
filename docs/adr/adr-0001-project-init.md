# ADR-0001: Project initialization

## Context

Начинается публичный pet project PulseBoard.

## Decision

* Вести разработку публично.
* Использовать GitHub как основной источник правды.
* Документировать ключевые архитектурные решения через ADR.
* Разрабатывать продукт итеративно, начиная с Discovery.

## Consequences

* Появляется прозрачная история развития проекта.
* Упрощается подготовка портфолио и технических материалов.
