# PulseBoard — Product Vision v0.1

## Идея

Веб-платформа для анализа публичных компаний с акцентом на скорость работы с большими таблицами, удобный поиск метрик и AI-помощника.

## Для кого

* частные инвесторы;
* аналитики;
* разработчики финтех-продуктов;
* студенты финансовых направлений.

## Проблема

Большинство финансовых сайтов перегружены, медленно работают с большими таблицами и плохо подходят для быстрого сравнения компаний.

## Решение

PulseBoard предоставляет:

* мгновенную фильтрацию и сортировку тысяч компаний;
* настраиваемые колонки;
* графики ключевых метрик;
* сохраненные наборы фильтров;
* AI-помощника для объяснения показателей и поиска компаний по естественному языку.

## MVP

1. Авторизация.
2. Поиск компаний.
3. Таблица компаний.
4. Сортировка и фильтры.
5. Страница компании.
6. Графики.
7. Избранное.

## Что НЕ входит в MVP

* брокерские функции;
* реальные сделки;
* платежи;
* социальные функции;
* мобильное приложение.

## Технологии (предварительно)

* Frontend: Nuxt 4 + Vue 3 + TypeScript
* Backend: NestJS
* Database: PostgreSQL
* Cache: Redis
* Infra: Docker + Nginx
* Charts: ECharts
* AI: OpenAI API / совместимый провайдер
